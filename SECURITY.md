# Security Policy & Audit Status

## Security Disclaimers & Audit Status

> [!IMPORTANT]
> **Audit Status:** XDR-Lens is open-source developer tooling. The web application client and diagnostic parser operate entirely client-side in the browser and do not store private keys, secret seeds, or user credentials. However, it has not undergone a formal third-party security audit.

## Reporting a Vulnerability

If you discover a potential security vulnerability within **XDR-Lens**, please disclose it responsibly:

1. **Do NOT** open a public GitHub issue.
2. Email lead maintainer directly: **abdulmalikojo2@gmail.com**
3. Include detailed information:
   - Type of issue (e.g. XSS, input handling flaw, dependency vulnerability).
   - Step-by-step instructions to reproduce the issue.
   - Proof-of-concept payload if applicable.

We will acknowledge receipt of your vulnerability report within 48 hours and work on a prompt security patch.
